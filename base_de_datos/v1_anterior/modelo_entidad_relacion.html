  usuarios {
    int id_usuario PK
    varchar nombre
    varchar correo UK
    varchar telefono
    varchar ciudad
    varchar password_hash
    enum rol
    datetime fecha_registro
  }
  cotizaciones {
    int id_cotizacion PK
    int id_usuario FK
    int id_tipo_trabajo FK
    int id_tipo_cubierta FK
    int id_tipo_estructura FK
    int id_diseno FK
    int id_plastico FK
    decimal largo
    decimal ancho
    decimal altura
    text observaciones
    enum origen
    decimal costo_materiales
    decimal costo_mano_obra
    decimal total
    datetime fecha
  }
  detalle_cotizacion {
    int id_detalle PK
    int id_cotizacion FK
    int id_material FK
    decimal cantidad
    decimal precio_unit
    decimal subtotal
  }
  materiales {
    int id_material PK
    varchar nombre
    varchar unidad
    decimal precio_unit
  }
  reglas_material {
    int id_regla PK
    int id_diseno FK
    int id_tipo_estructura FK
    int id_material FK
    decimal cantidad_por_m2
  }
  tarifas_mano_obra {
    int id_tarifa PK
    int id_diseno FK
    decimal precio_m2
  }
  tipos_trabajo {
    int id_tipo_trabajo PK
    varchar nombre
  }
  tipos_cubierta {
    int id_tipo_cubierta PK
    varchar nombre
  }
  tipos_estructura {
    int id_tipo_estructura PK
    varchar nombre
  }
  disenos {
    int id_diseno PK
    varchar nombre
    varchar descripcion
  }
  plasticos {
    int id_plastico PK
    int id_tipo_cubierta FK
    varchar nombre
    varchar calibre
    tinyint porcentaje_sombra
    decimal precio_m2
  }
  categorias_galeria {
    int id_categoria PK
    varchar nombre
  }
  galeria {
    int id_foto PK
    int id_categoria FK
    varchar titulo
    varchar descripcion
    varchar ubicacion
    varchar ruta_imagen
    date fecha
  }

Descripción de las entidades

TablaPara qué sirve
usuariosClientes registrados y administradores.
cotizacionesCada cotización: opciones elegidas, medidas, observaciones y totales. El campo origen indica si vino del formulario o del chat.
detalle_cotizacionLista de materiales de cada cotización con cantidad, precio y subtotal. El precio queda guardado aunque después cambie.
materialesCatálogo de materiales con su unidad y precio.
reglas_materialCuánto material necesita cada diseño según la estructura, por m². Se edita desde el panel de administrador.
tarifas_mano_obraPrecio de la mano de obra por m² según el diseño.
tipos_trabajo, tipos_cubierta, tipos_estructura, disenosCatálogos de las opciones del cotizador.
plasticosPlásticos (calibre) y mallas saran (% de sombra) con su precio por m².
galeria, categorias_galeriaFotos de trabajos realizados y sus categorías.
